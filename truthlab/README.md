# TruthLab: AI-Guided Misinformation Simulator

TruthLab is a web-based software application developed in Python. It trains users to identify fake, AI-generated, manipulative, and misleading online content through interactive simulations and AI-coach style feedback.

## Purpose

Misinformation spreads quickly because many users react emotionally before checking evidence. TruthLab helps users practice safer digital habits by reviewing simulated online posts, making decisions, and receiving immediate explanations.

## Main Features

- Simulated social media/news feed
- Interactive decisions: Trust, Doubt, or Report
- AI-coach style feedback after each answer
- Skill-based scoring system
- Final Digital Literacy Report
- Personalized learning tip based on the user's weakest skill

## Computer Science Principles Demonstrated

- Data loading and validation
- Modular programming

- Scoring algorithms
- State management
