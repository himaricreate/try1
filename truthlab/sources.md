# Sources and Assets

## Project Assets

The first version of TruthLab uses text-based educational scenarios created specifically for this simulation. No copyrighted images, logos, news articles, or private datasets are included.

## External Libraries

- Streamlit: used to build and deploy the interactive web application interface.
- Pandas: used to load and manage scenario data.
- Pillow: included for future image-handling features.
- Matplotlib: included for future score visualization features.

## Scenario Notes

All scenarios are fictional and designed for educational purposes. They are based on common misinformation and scam patterns, including:

- miracle health cure claims
- phishing messages
- fake scholarship scams
- manipulated screenshots
- misleading statistics
- emotional sharing pressure
- AI-generated or out-of-context image claims

## Citation Plan for Final Submission

Before final submission, the project portfolio may cite public digital literacy and misinformation resources, such as:

- Cybersecurity and phishing awareness resources
- Public health misinformation guidance
- Media literacy education resources
- AI-generated media literacy guidance

The current MVP avoids copyrighted assets by using original fictional examples.
